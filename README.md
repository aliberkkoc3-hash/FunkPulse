# 🎤 FunkPulse: BF Edition

Boyfriend'in renk paletinden ilham alan karanlık bir VS Code teması! Koyu lacivert, elektrik mavisi, canlı kırmızı ve koyu kızıl bir araya geldi. Sonuç mu? Kod yazarken bile ritim tutmak isteyeceğin bir editör. Tabii kodların ritim kaçırırsa o bizim sorunumuz değil. 💀

Editör, sözdizimi renklendirmesi, sekmeler, yan menü, terminal, açılır menüler, paneller, durum çubuğu, ayarlar ve daha fazlası bu renk cümbüşüne dâhil. Kısacası VS Code'a BF'in gardırobunu giydirdik. 🎨

## ⚡ VSIX ile kurulum / güncelleme

1. VS Code'u aç ve `Ctrl + Shift + X` tuşlarına bas. Eklentiler menüsüne hoş geldin!
2. Sağ üstteki `...` menüsüne tıkla ve **VSIX'ten Yükle...** seçeneğini seç.
3. `FNF_Neon_BF_Edition.vsix` dosyasını bulup seç. Eski FNF Neon sürümü hâlâ sahnedeyse `Ctrl + K`, ardından `Ctrl + T` yap ve **FNF Neon: BF Edition** temasını seç.
4. Tema hâlâ eski hâlindeyse Komut Paleti'ni aç (`Ctrl + Shift + P`) ve **Developer: Reload Window** komutunu çalıştır. Biraz da VS Code kendine gelsin. 🫡

## 🎨 Renklerle oynamak mı istiyorsun?

`themes/fnf-neon-color-theme.json` dosyasını aç.

- `colors`: VS Code arayüzünün renkleri. Menüler, paneller ve diğer görsel alanlar burada.
- `tokenColors`: Kodların sözdizimi renkleri. Değişkenler, anahtar kelimeler ve diğer kod parçaları burada.
- `semanticTokenColors`: Editörün dil sunucusundan aldığı anlamsal renklendirme ayarları burada.

Renkleri değiştir, dene, bozarsan geri al. Geliştiricilik dediğin biraz da budur. Tabii yedek almayı unutma; sonrasında klavyeyle düello yapmak istemeyiz. 💀
